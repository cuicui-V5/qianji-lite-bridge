两阶段流水线与限流调度流程

无论来自麦克风录音、悬浮胶囊还是局域网 HTTP 请求，均统一经历以下标准化通道：

Step 01

音频录制 / HTTP 接入

M4A 高清录音或接收局域网 RESTful POST 载荷。

Step 02

极速转录 (ASR)

百度极速版 (80001) 引擎，平均 600ms 完成高精度中文转写。

Step 03

AI 结构化解析

DeepSeek-flash 自适应思考直出 JSON 账单，多笔复杂消费自动拆解。

Step 04

强校验与 3.2s 队列

过滤幻觉分类，合规账单压入 Channel，间隔 3.2s 唤起钱迹并切回网关。

常见问题与解答

解答关于保活、API Key 安全以及钱迹客户端联动的常见疑惑。

Q: 百度语音识别与 DeepSeek 密钥如何获取？

百度语音识别可在百度智能云控制台免费开通“语音技术”服务（极速版每月免费额度充足），填入 AppID、API Key 与 Secret Key 即可；DeepSeek 可在官方开放平台申请 API Key，或使用任何兼容 OpenAI 协议的第三方中转服务。

Q: 为什么要设置 3.2 秒安全限流？

钱迹官方接口设有 3 秒防刷机制。如果一句话被 AI 拆分为多笔账单，或者局域网并发调用，瞬间连续唤起会被钱迹拦截。本网关内置 FIFO 协程通道以 3,200ms 安全匀速唤起，保证 100% 成功入库。

Q: 是否需要 Root 或复杂的无障碍权限？

完全不需要！本工具完全通过 Android 原生 URL Scheme (`qianji://publicapi/addbill`) 进行正规集成。仅需要常规的网络、麦克风权限以及悬浮窗权限（如需全局胶囊）。

Q: 如何保证在锁屏或后台下持续作为网关运行？

前台运行时应用会自动启用常亮开关；如需作为常驻家庭网关，请在手机系统设置中将本应用电池策略设置为“无限制 / 允许后台高耗电”，防止被系统后台查杀。
